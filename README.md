# Aarohi – Girl Education Empowerment Platform

Aarohi is a multilingual web platform designed to help girls after 10th grade discover career guidance, scholarships, government schemes, learning resources, internships, and educational opportunities in one place.

## Functionality

* **Career Guidance:** Provides career roadmaps, higher education guidance, and information about career opportunities.
* **Scholarships & Opportunities:** Provides information about scholarships, internships, fellowships, and educational programs.
* **Government Schemes:** Displays information about women-focused government schemes, financial assistance, and skill-development programs.
* **Learning Resources:** Provides resources for programming, communication skills, certifications, and skill development.
* **Educational Events:** Provides information about workshops, seminars, competitions, and career-related events.
* **Multilingual Support:** Content is available in English, Telugu, and Hindi.
* **User Authentication:** Supports user registration and login.

## Technologies Used
HTML5, CSS3, JavaScript, React.js, Vite, Node.js, Express.js, MongoDB
